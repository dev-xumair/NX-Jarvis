============================================================
PART A — ZERO-TRUST PRINCIPLE
============================================================

The central rule:

NO FEATURE IS CONSIDERED WORKING UNTIL IT IS EXECUTED AND VERIFIED.

For every feature:

1. Find the implementation.
2. Inspect its dependencies.
3. Execute it.
4. Observe actual output.
5. Compare against expected behavior.
6. Verify side effects.
7. Test failure cases.
8. Record evidence.
9. Mark the truth state.

Truth states:
VERIFIED
PARTIALLY_VERIFIED
IMPLEMENTED_UNVERIFIED
FAILED
BLOCKED
UNAVAILABLE_ON_CURRENT_HOST
NOT_IMPLEMENTED
REMOVED_AND_VERIFIED

Never write "working" based only on source code existence.
